# Lucide icons

Vendored from https://github.com/lucide-icons/lucide tag `1.64.0` (ISC, see LICENSE).
Unmodified SVG sources; rasterized at build time by `tools/build-ui-icons.py`.
Add an icon by copying its SVG from the same tag and listing it here.

Help uses `circle-question-mark` (formerly `circle-help` upstream).

Launcher tiles use `hand` (Welcome), `terminal`, `folder` (Files), `file-text`
(Editor), `sunrise`, `monitor` (System), `sliders-horizontal` (Meridian) and `package`.

Observatory uses `activity` (its own tile and Performance), `cpu`, `memory-stick`
and `list` (Processes).

Equinox uses `hard-drive` (its tile and disks), `list` (Plan) and `clock` (History).
