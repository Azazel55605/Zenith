# Lucide icons

Vendored from https://github.com/lucide-icons/lucide tag `1.64.0` (ISC, see LICENSE).
Unmodified SVG sources; rasterized at build time by `tools/build-ui-icons.py`.
Add an icon by copying its SVG from the same tag and listing it here.

Help uses `circle-question-mark` (formerly `circle-help` upstream).

Launcher tiles use `hand` (Welcome), `terminal`, `folder` (Files), `file-text`
(Editor), `sunrise`, `monitor` (System), `sliders-horizontal` (Meridian) and `package`.

Observatory uses `activity` (its own tile and Performance), `cpu`, `memory-stick`
and `list` (Processes).

Equinox uses `hard-drive` (its tile and disks), `list` (Plan) and `clock` (History).

Horizon uses `house`, `download`, `folder`, `hard-drive` (places and devices), `arrow-left`,
`arrow-right`, `arrow-up` (history), `layout-grid` and `list` (views), `panel-right` (information),
`search` (filter), `file`, `file-text`, `file-code`, `file-archive`, `image`, `link` (items),
`copy`, `scissors`, `clipboard-paste`, `pencil`, `trash`, `folder-plus`, `refresh-cw`,
`arrow-down-a-z`, `eye-off` (menu) and `columns-2` (split, HZ2).

Sunset uses `lock`, `log-out`, `rotate-ccw` and `power` (its four actions), `user` (who is
signed in), `triangle-alert`, `file`, `terminal`, `check` and `x`.

Beacon uses `shield` (VPN) and `activity` (Traffic) from here, `clock` for History, and ships `cable` (Wired),
`wifi-off` (no Wi-Fi adapter) and `stethoscope` (Diagnostics) in its own package (`userland/beacon/icons`, the same
tag): `zenith-icons` is at the package limit of 64 files. The taskbar's network and sound centers use `network` and
`volume-2` (a strike marks muted).
