Using Nebula

Click a link to open it. The arrows in the toolbar go back and forward; the round arrow reloads the page and becomes a cross that stops it while it loads.

The address field shows the site in bold. Click it, or press Ctrl+L, to type an address. An address without https:// or http:// opens over HTTPS. An absolute file path opens a local HTML document.

Click the icon at the start of the address for Page info. A closed lock means Zenith verified the displayed HTTPS page. Nebula can keep opening connections as you browse.

The menu at the right opens your bookmarks and recent pages. Click the star beside a page to save it, or click it again to remove it. As you type in the address field, use the arrow keys and Enter to open a matching bookmark or recent page. Suggestions stay on this computer. Right-click Back or Forward to choose a page, or right-click a link to open it or copy its address.

JavaScript

New tabs start with scripting off. Open the browser menu and choose Allow JavaScript and reload to run classic scripts. For a local page the choice covers that file. For a website it covers pages with the same scheme, host and port in this tab. Choose Block JavaScript and reload to turn it off. Page info shows the current state.

Try the click counter with scripting off, then enable it and click twice. From a desktop terminal, native run netsurf --javascript https://example.org/ starts a tab with scripting enabled for that origin.

Nebula leaves scripts off on pages that enforce a Content Security Policy. JavaScript modules and web APIs such as fetch() are still under development.

Keys

  • Ctrl+T: new tab; Ctrl+W: close the tab; Ctrl+Shift+T: reopen the last closed tab
  • Ctrl+Tab, Ctrl+Shift+Tab: next and previous tab; Ctrl+1 to Ctrl+8: that tab; Ctrl+9: the last tab
  • Middle-click or Ctrl+click a link: open it in a new tab behind this one
  • Ctrl+Shift+S, or the first button in the toolbar: hide or show the sidebar
  • Ctrl+L: type an address
  • Alt+Left, Alt+Right: back, forward
  • Alt+Home: bookmarks and history
  • Ctrl+D: save or remove a bookmark
  • Ctrl+R or F5: reload; Esc: stop loading
  • Ctrl+F: find on page; Enter and Shift+Enter: next and previous match
  • Ctrl+U: view the loaded page source. Scroll with the wheel or arrow keys, or use Page Up, Page Down, Home and End. Press Esc to return to the page.
  • Ctrl+Plus, Ctrl+Minus, Ctrl+0: zoom in, out, back to 100 %
  • Ctrl+C: copy the selected text
  • Ctrl+Q: close Nebula

A link to a downloadable file opens a card with its name and a button to copy its address. Saving downloads is planned.
