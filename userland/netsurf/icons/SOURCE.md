# Nebula icons

Lucide icons from https://github.com/lucide-icons/lucide tag `1.64.0` (ISC, see LICENSE), the same tag as
`userland/ui/icons`. They are unmodified SVG sources, rasterized at build time by `tools/build-ui-icons.py` and
installed by the browser package because `zenith-icons` is at its package file limit.

`book-open` (Using Nebula), `chevron-up` (previous match), `code` (Scripts), `ellipsis` (menu), `globe`
(built-in pages, Connections), `lock-open` (pages without TLS), `minus` and `plus` (zoom), `rotate-cw` (Reload),
`star` (bookmarks, stage B4).
`panel-left` (hide or show the sidebar), `moon` (put a tab to sleep), `undo-2` (reopen a closed tab).
